# فكّر بسرعة — مصدر التطبيق للمراجعة الأمنية

هذا المستودع يحتوي على نسخة المصدر الآمنة للعبة Android العربية «فكّر بسرعة» (Think Fast)، وهي لعبة أسئلة تعتمد على جلسات قصيرة ومؤقت 25 ثانية ونظام مساعدات بعملات وإعلانات مكافأة.

## بنية المشروع

| المسار | الوصف |
|---|---|
| `client/` | واجهة React ومنطق اللعبة ومكوّنات الشاشة |
| `server/` | الخادم واختبارات السلوك والمنطق |
| `shared/` | الأنواع والثوابت المشتركة |
| `android/` | مشروع Capacitor/Android وكود الإعلانات الأصلي |
| `drizzle/` | مخطط قاعدة البيانات وملفات الترحيل |
| `scripts/` | أدوات بناء وفحص المحتوى |
| `package.json` | تبعيات وأوامر JavaScript/TypeScript |
| `pnpm-lock.yaml` | الإصدارات المثبتة للتبعيات |

## تشغيل الفحوص المحلية

بعد تثبيت Node.js وpnpm، شغّل `pnpm install` ثم `pnpm test` للاختبارات و`pnpm check` لفحص TypeScript. لبناء الواجهة والخادم استخدم `pnpm build`. يتطلب بناء Android وجود Android SDK وJDK متوافقين مع إعدادات Gradle داخل مجلد `android`.

## فحص Snyk المقترح

من جذر المستودع، استخدم `snyk test --file=package.json --package-manager=pnpm` لفحص تبعيات JavaScript. وللتبعيات Android/Gradle، استخدم تكامل Snyk المناسب لمشروع Gradle أو افحص ملف `android/app/build.gradle` من خلال واجهة Snyk. لا ترفع ملفات الأسرار أو مفاتيح التوقيع إلى Snyk أو GitHub.

## ملاحظات أمنية

هذه نسخة مصدر منقّحة للمراجعة. تم استبعاد مفتاح توقيع Android، وملفات البيئة، وبيانات اتصال قاعدة البيانات، وملفات البناء و`node_modules`. معرفات الإعلانات العامة ليست أسرارًا، لكن لا ينبغي اعتبارها بديلًا عن حماية أي مفاتيح سرية أخرى.

راجع خصوصًا منح العملات بعد اكتمال الإعلان فقط، تخزين الرصيد، صلاحيات Android، الروابط الشبكية، مدخلات الخادم، وأي بيانات حساسة مضمّنة في التطبيق.
